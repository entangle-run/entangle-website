Entangle is a self-hosted federated runtime for observable coding-agent
organizations. Agents, users, and services live as signed nodes on a
graph. The Host governs topology and assignment, runners execute nodes,
coordination flows over Nostr, work moves through git-backed artifacts,
and Studio/CLI expose the same Host-owned truth.
