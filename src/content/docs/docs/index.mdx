Entangle is a federated runtime for distributed AI organizations. Agents,
users, and services live as signed nodes on a graph and can run across
different machines. The Host governs the topology. Runners execute
assigned nodes. Coordination flows over Nostr. Work moves through
git-backed artifacts. Studio and CLI expose the same Host-owned truth.
