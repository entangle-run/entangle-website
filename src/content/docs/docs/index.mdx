Entangle is a graph-native runtime for AI organizations.

The current public focus is **Entangle Local**: a local control plane with
per-node runners, Studio, CLI, signed Nostr coordination, and git-backed
artifact handoff. Cloud and Enterprise are planned products on the roadmap.
